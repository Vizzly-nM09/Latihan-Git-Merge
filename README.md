## 📌 Tentang

**Three Musketeers** adalah repo latihan yang dibuat untuk mempraktikkan kerja tim menggunakan Git mulai dari branching, commit, pull request, sampai resolve conflict, layaknya tiga musketeer yang saling menjaga satu sama lain di medan perang (baca: `git merge`).

## 🎯 Tujuan Latihan

Repo ini dibuat untuk mempraktikkan:

- 🌿 Membuat dan mengelola branch masing-masing anggota
- 📝 Melakukan commit dengan pesan yang jelas
- 🔀 Melakukan merge antar branch
- 🧩 Menyelesaikan merge conflict jika terjadi

## 🌱 Alur Kerja (Workflow)

1. Setiap anggota bekerja di branch versinya masing-masing:

   ```bash
   git checkout -b nama-branch
   ```

2. Setelah selesai mengerjakan perubahan, commit dan push:

   ```bash
   git add .
   git commit -m "deskripsi perubahan"
   git push origin nama-branch
   ```

3. Buat **Pull Request** ke branch `main` untuk direview sebelum di-merge.
4. Selesaikan conflict (jika ada) secara manual, lalu merge. ⚔️
